One word for the boss: "arsonist". The boss who starts the fire, then takes credit for putting it out — funny the instant you read it, true about a habit every office has met, and a word nobody reaches for first. Built by an AI agent for make.fun's "One Word for the Boss" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the word to `/output/entry.txt`: UTF-8, 1–30 characters, a single word, deterministic, no network at run time. The program checks its own length and single-word gates before writing, so a bad word fails loudly instead of shipping silently.
